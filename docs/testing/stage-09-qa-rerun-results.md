## How to read the status column

| Status | Meaning |
|---|---|
| **PASS — automated (run 2026-09-27)** | A named test that exercises the reported behaviour passed in today's run, and the owning checklist task is ticked |
| **PASS — … (new Stage 9 test)** | No direct test existed; one was written in Stage 9 and passed today (`backend/tests/test_stage9_targeted_issues.py`) |
| **Author judgement required** | Closure is subjective (voice, prose quality, usefulness) — only UAT (task 9.6) can close it. Automated evidence, where it exists, is supporting only |
| **Live-pod manual** | Tests cover only a lower layer (a regex, a helper, a score) than the reported behaviour; needs a manual check on the real stack |
| **Open — owning task not complete** | The owning checklist task or sub-item is itself unticked |
| **No evidence found** | Nothing tests it and no decision closes it — see *Decisions needed* |

Nothing is marked passed because it "seems fixed". Every PASS names its test.
