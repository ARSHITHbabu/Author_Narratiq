# Versions are pinned to the known-good set this app was validated against.
# Floating ranges (>=) previously let a fresh install pull a newer release whose
# behaviour differed (e.g. SQLAlchemy bind-parsing, async client changes), which
# is how "it worked, then broke after a reinstall" happened. Pin, don't float.
#
# Stage 10 (task 10.3; Stage 9 finding D2): this file is now the ONE source of
# truth for the backend's Python packages. Every pin below equals the version
# that is actually installed and running on the pod, where the full backend
# suite passes (2026-09-29: 738 passed before the Stage 10 changes). Previously
# the pins had drifted from reality (FastAPI 0.111 pinned, 0.141 running) and
# four required packages were missing (rapidfuzz, jellyfish, websockets,
# verovio). start-narratiq.sh installs from this file; the backend container
# image (backend/Dockerfile) installs from it too.
#
# vLLM is NOT here: it runs as its own server with its own pinned install
# (start-narratiq.sh VLLM_VERSION; requirements.vllm.txt). Several web packages
# below (fastapi, uvicorn, pydantic, openai) are shared with vLLM 0.9.2, and the
# versions here are the ones pip resolved alongside it on the pod.
